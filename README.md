# Soko & Co. storefront

Open `market.html` to view the storefront. The site uses local HTML, CSS, JavaScript, and the product images in `images/`; no build step is required.

## Files

- `market.html` — storefront entry point and shop/cart dialogs.
- `market.css` — shared layout, responsive styling, and page components.
- `market-products.js` — shared catalog data and product image paths.
- `market.js` — catalog filters, category rails, cart, and demo checkout.
- `product.html` and `product-detail.js` — product details and related finds.
- `contact.html` and `contact.js` — local demo contact form.
- `faq.html` — store help and demo limitations.
- `site-nav.js` — responsive navigation behavior.
- `wishlist.js` — browser-local saved products.
- `images/` — all images referenced by the storefront and product catalog.

Checkout and contact submissions are local demos; they do not send payments, orders, or messages.
